# Agile Approach

Bu projede Agile prensipleri benimsenmiştir.

## Temel Prensipler

- Küçük adımlarla ilerleme
- Değişime açık olma
- Sürekli geri bildirim alma
- Çalışan parçalar teslim etme

## Bu Projede Uygulama

- Çalışma yöntemi olarak **Kanban** kullanılacaktır
- Sprint zorunluluğu yoktur
- İşler küçük parçalara bölünerek ilerlenecektir

## Neden Agile?

- Gereksinimler netleştikçe değişebilir
- Erken ve sık geri bildirim alınmak istenmektedir
- Büyük planlar yerine adım adım ilerlemek daha uygundur
