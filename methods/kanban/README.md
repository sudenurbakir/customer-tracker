# Kanban Approach

Bu projede işler Kanban yöntemi ile yönetilecektir.

## Neden Kanban?

- İşler sürekli akış halinde ilerleyecek
- Sprint zorunluluğu olmayacak
- Değişikliklere hızlı uyum sağlanacak
- Aynı anda fazla işle uğraşmak engellenecek

## Temel Prensipler

1. İşleri görselleştir (Board üzerinde tut)
2. Aynı anda üzerinde çalışılan iş sayısını sınırla (WIP Limit)
3. Akışı ölç ve iyileştir
4. Mümkün olduğunca küçük işlerle ilerle

## Bu Projede Nasıl Uygulayacağız?

- Jira üzerinde Kanban board kullanılacak
- Sütunlar: To Do → In Progress → Done
- In Progress sütununda en fazla 3 iş bulunacak
- İşler mümkün olduğunca küçük ve net tanımlanacak
