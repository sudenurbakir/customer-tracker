# Definition of Done

Bir iş ancak aşağıdaki şartlar sağlandığında “Done” sayılır:

1. İlgili dokümantasyon güncellenmiştir (gerekliyse)
2. İş kuralına uygun çalışıyordur
3. Temel kontroller yapılmıştır
4. Board’da Done sütununa alınmıştır
5. Başka bir engel veya eksik bırakılmamıştır

Not: Kod yazma aşamasında bu liste genişletilecektir (test, review vb.).
